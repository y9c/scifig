# scifig

Publication figures with plain matplotlib. No package.

## Copy this to your agent

> Clone this repo: `git clone https://github.com/y9c/scifig.git && cd scifig`.
> Then `make venv` and `python examples/grouped_bar.py`. If it writes `examples/out/grouped_bar.pdf`, the env works.
> Then read `skill/SKILL.md` and make my figure from the recipes in `examples/`.
