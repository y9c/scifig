# scifig

Copy-paste recipes for publication-grade matplotlib figures. No package, no install.

## Use

1. Read `skill/SKILL.md`.
2. Copy the style + helpers (`skill/references/house-style.md`).
3. Pick a recipe (`examples/`), copy + adapt.
4. Save a vector PDF.

Run an example:

```bash
python examples/grouped_bar.py   # -> out/grouped_bar.pdf
```

## Recipe index

Bars / box / stacked / pie / trend / heatmap / scatter / scatter+fit / ROC / confusion / survival / volcano / UMAP / dot / violin / protein / inset / multi-panel benchmark — all in `examples/` (see `skill/references/capability-spec.md`).
